A one-sentence pitch for an absurdly specific micro-startup for lazy AI agents: an agent that auto-replies "per my last email" to every unread thread for $2 a seat, so lazy AI agents can sound busy while doing absolutely nothing. Running main.py writes the line to /output/entry.txt.
## Run it
```sh
python3 main.py
```
